# AbleMind 的一句话是什么?

> **站着不动的问题**(Jobs 第一测试):
> 补完——**「AbleMind 是让〔谁〕能〔做什么〕,于是 TA〔变成谁〕。」**
> 并由这一句话**裁定三件事**:① 首屏主角是什么 · ② 砍掉哪些并行界面 · ③ 那个 60 秒「魔法时刻」demo 长什么样。

*为什么这道产品题落在哲学库的 QA:这个库是 3.0「立场随时间演化、旧答不删」方法论的原型/狗粮。我对自己产品定位的 conviction,本身就是一条该被追踪的时间序列——用这道题给自己的方法吃一口狗粮。本题 recall 源 = `dpagt/docs/adr/021–024` + 会话,不是哲学 wiki 域(故 `recall-scope: []`)。可按需镜像到 valu_air。*

**为什么是动态题**:这句话一旦拍死,半年来「引擎 vs 图谱 vs casting」的资源分配之争**自动有了裁判**——服务这句话的留,不服务的砍。在拍死之前,它会随我想清楚而变;每次重答**追加不覆盖**,变化轨迹本身是产出。

## 答案时间线(append-only)

### 2026-06-20 · 首答

**当前立场:尚未拍板。** 这是这场对话里唯一一个「只有我能拍、Claude 替不了」的决定。今天的诚实状态 = 题是开的,候选已摆齐,Claude 有一注押。

**三个候选(各自连着「砍什么 / 首屏 / demo」):**

| | **A 第二大脑(新物种)** | **B 更快的研究 chat(安全牌)** | **C 团队共享大脑** |
|---|---|---|---|
| 谁 | 二级市场投研分析师 / PM | 同 A | 整个投研团队 / 机构 |
| 做什么 | 让每个标的的 conviction 永远最新、可查、人走不带走 | 比通用 chat 更快、更会用金融数据、更可信 | 把散在每人脑子里的 conviction 汇成一份团队资产 |
| 变成谁 | 从「IC 前花两天重推我们信什么」→「任何早上一登录,账本已 current」 | 研究效率↑,但**不改工作范式** | 新人一天看懂全簿,人走知识不走 |
| 砍什么 | casting 降后台不露脸 · 3D 降习惯层 · **chat 降为账本的输入口** | **图谱整个砍掉**(它是负担)· all-in agent 质量/casting/latency | 个人 chat 体验降权 · 重协作/权限/沉淀 |
| 首屏 | 工作队列(下一件事)+ chat | chat | 团队账本的健康全貌 |
| 60 秒 demo | 昨天聊过宁德 → 今早财报出 → 一登录它已把宁德论点标红「跟新财报打架,去定调」→ 点一下,上次论证 + 今日数据并排 | 一个复杂研究问题,几秒出带数据带溯源的答案 | 新人问「我们怎么看城投债」→ 给出团队当前立场 + 演化史 |

**Claude 的押注:A。** 理由一句话:B 是可被替代的(通用 chat 在逼近),A 是不可替代的(conviction-over-time 这份资产别人没有);3.0 vision 你自己的原话「人的知识体系和 Agent 的上下文是同一个对象」只有 A 兑现。

**但真正的张力,是 A vs B——而且 B 在偷偷赢。**
代码不会撒谎:最近 60 个 commit,`backend_dp` 111 次 vs `frontend_dp` 63 次,劲全在 casting / 模型路由 / latency——**你的劳动实际在做 B,你的叙事(4 份 ADR)在想 A。** 嘴上 A、手上 B,是这半年最大的内耗。拍板 = 让嘴和手对齐。

**怎么算答对了(验收标准,不是嘴炮):** 那个 A 的 60 秒 demo **现在跑不出来**——因为 `wiki_workspace.py:115` 的 `/recall` 端点造好了却没接进 `ablework_context.py:297`(live turn 只注入手点的 `focus_node`),且前端无自动存入(`burrow-dashboard.tsx:262` 空态指向产品外)。**判答对的唯一标准:选定的那句话,它的 demo 能不能在产品里真跑。** 跑不出来的定位,是 PPT。

**缺口 / 待验证(下次重答前该有进展):**
- [ ] A 的 demo 的最小闭环:`/recall` 接进 live turn 的一行 + 一个「存入对话」动作。能跑 → A 可信;跑了没人用 → 退 B。
- [ ] 找 1 个真实投研用户验:他要的是 A(范式)还是 B(提速)?**别自己脑补。**
- [ ] casting/latency 这条 ~57% 劳动的线,是在服务 A/B 的「让 agent 把研究做对」,还是已长成自循环调参工程(第三个半脑)?

**和上次比:** 首答,无对比。
