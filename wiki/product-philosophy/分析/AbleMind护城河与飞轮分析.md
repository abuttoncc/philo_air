# AbleMind 护城河与飞轮分析

> 派生视图（2026-06-20~21 三场讨论结晶）。把 [[竞争优势模式]] 的护城河判据 + [[不可替代性拷问]]
> 压到用户在建的产品 **AbleMind**（智能体工作区 3.0 的具体实例）上。**AbleMind / 「3.0 工作区」本身不本体化**
> （是用户的产品/工具，非哲学知识）——本页是 capital-allocation 与 product-philosophy 概念的应用派生，
> 删了不影响本体。姊妹页 [[乔布斯产品哲学映射智能体工作区3.0]]（Jobs 产品六原则 → 3.0 设计）；
> 本页换**护城河/资本配置镜头**看同一产品。

## 1. 真实竞品教训：Cursor 死于薄分发层，不是死于"单模型依赖"

最反直觉的一条经验数据——**Cursor 本来就是多模型的**（用户可自选 Claude/GPT/Gemini）却被挤死；
**Claude Code 是纯单模型的**（只有 Claude）却在赢。**赢家比输家更"模型锁定"。** 这把"单一模型依赖=死因"
直接证伪。用 [[竞争优势模式]] 复制成本反演判，Cursor 整个是"白酒"：

- **不拥有模型的薄分发层**——站在一个**既是供应商又是竞争对手**的模型之上（付零售价、对方拿批发价、毛利≈0）。
- **零转换成本**——产出（代码）落在用户 repo，人走带走，没有任何留存。
- **无累积专有资产**——没有一份越用越厚、抄不走的东西。

> 真死因 = 薄分发层 + 零留存 + 供应商即对手，**与模型数量无关**。
> 「我要做多模型」若是冲着"治 Cursor 的病"，药没对症。

（已核实事实，作论据非节点：Cursor 2025 爆发 $100M→$2B ARR；Anthropic 占其成本 ~40–50%、为其最大客户；
Ramp 代理口径份额 41%[2025/6]→26%[2026/5]、Claude Code 升至 ~50%；但 Cursor 收入仍涨、2026/6 被 SpaceX
$60B 收购——**跌的是份额/毛利/战略地位，不是日活断崖**；定价挤压 vs 体验落后两说并存，未定论。）

## 2. 多模型 = 船票，不是船

模型无关 + eval 上岗适配 + 异构拼接（DeepSeek 缺多模态自己拼、对话模式做实践）**本身是白酒易仿**
（OpenRouter / LiteLLM / Vercel AI SDK 现成）——是**先发优势，不是护城河**。但它有真价值：**拆脆弱性**
（永不被任一家定价绞杀）= 结构性**生存优势**；而活着是护城河复利的前提，公司先死、账本再厚也没用。

> **定性：多模型是让你活到账本变厚的「船票」，不是「船」。**
> 拆脆弱性（防守）≠ 建护城河（进攻）——这两件事在"多模型即护城河"的主张里被叠在了一起。

steel-man（[[死亡过滤器]] 式自检后仍立）：真·尖刺格局里，吃透"哪个子任务派给谁"并拼接补齐能力缺口的
**编排**能交付单模型给不了的体验；若够深（延迟优化/缺口填补/逐模型领域调优 + 多年 eval 数据），复制非一日之功。
**但这条最强论恰好塌进下一节**——它的承重点是"多年攒下的 eval/编排数据"，而那是不是护城河，只看它**专有**还是**商品**。

## 3. 主要矛盾（矛盾分析法结论）：异构产出沉淀在哪

用矛盾分析法拆开，**主要矛盾 = 产出沉淀在用户处（零留存，答完即走）vs 沉淀进可累积的 conviction 账本
（转换成本，越用越黏）**。判据——解这条，其余矛盾全塌缩：

| 次要矛盾 | 主要矛盾解决后 |
|---|---|
| 路由 vs 资产 | 路由降格为账本的**配送机制**，资产是墙 |
| eval 标准答案从哪来 | 账本本身**就是** eval 语料（"历史已兑现的判断"=答案键）|
| 防守 vs 进攻 | 多模型=防守(table stakes)、沉淀=进攻(moat) |
| 用户无感 vs 有感 | 知道**藏路由（无感）露资产（有感）** |

**反向验证**：把路由/eval/拼接全做到顶却不碰这条 → 得到一台优秀的**商品路由器，零留存 = Cursor**，
护城河纹丝未动。**主要方面**：今天占支配地位的是"沉淀在用户处"（捕获泵退役、账本无源）→
**故 AbleMind 今天的性质 = Cursor 那侧的商品路由器，护城河真值 = 0，不因模型少，因产出外流。**

## 4. eval 的护城河寄生在专有累积语料上

"取众家之长"真正的承重点是 **eval 的标准答案从哪来**：公开基准当裁判 → 你的路由和别人收敛到同一套 = 白酒；
**"该用户/机构历史已兑现的判断"当裁判 → 谁都拿不到 = 不可复制**。但专有 eval **只在账本真在累积时才存在** →
又绕回那枚生死手（捕获泵）。**连"eval 选模型"这件最像护城河的事，其护城河性也寄生在账本累积上，
而非寄生在 eval 工程本身。**

## 5. 矛盾性质：非对抗性为体，对抗性为枢

- **非对抗性为体（可重设计调和）**：产出**能同时**落用户工作流（无感）+ 双写一条结构化痕迹进账本（沉淀），
  两侧不必二选一——用"重设计"解（飞轮"存入"半 = 双写架构：路由自由，但出口必沉淀）。
- **对抗性为枢**：**自动点火 vs 手动触发**。默认引力把产出冲向用户侧（自然态=Cursor），要它沉淀必须有
  主动架构力持续施加。**最致命的方法错配 = 把捕获泵当非对抗性的"锦上添花、建好挂手动即可"，
  而它实为对抗性的"必须自动点火，否则整条护城河是假的"**——这正是 [[不可替代性拷问]] 里
  "若不可替代性只是视觉整合、维护成本会超过收益"的同一判决：需人手维护的账本不是护城河。

## 6. 飞轮接线：进料口是被漏建的那半

飞轮两相——**存入**(对话→图谱) ｜ **养护**(图谱→派研→回灌)。产品精力天然涌向养护半（状态/交互/壳），
**进料口（把对话自动变成结构化候选）是反复被漏建的那半**，而它正是"用户上去积累、不做基础建设"
这条承诺的兑现处。这与 [[设计即如何运作]] 同源：让用户手动连接系统的两半（手点节点喂上下文）是
"谁干活"的哲学错误；自动捕获该是 [[隐形工艺]]。

## 7. 护城河升级阶梯与时间的双刃

- **升级阶梯**：个人转换成本 → 组织资本（人走知识不走）→ 真网络效应（机构间委派差异化专家 agent）。
  ②→③ 是从"转换成本护城河"跳到"网络效应护城河"的唯一通道。（注：真网络效应**不在** [[竞争优势模式]]
  十二式之列，是 conviction 资产复利到机构间互通时才浮现的增量档。）
- **时间的双刃**：先发优势 = 时间差（会被追平）；护城河 = 时间复利（买不到）——**同样是时间，
  是飞轮决定它站哪边**。时间对这类护城河是盟友，但只在飞轮转起来之后；在那之前，时间是在浪费。

## 一句话收口

> 护城河不是"我会取众家之长"（手艺，会被抄）；是"**只有我知道众家之中、对这类投研题谁最长——
> 因为只有我有那本随时间变厚、答完即沉淀进去的专有考卷**"。多模型是让我活到那本考卷变厚的**船票**，不是船。

## 个人立场（T1，交叉引用 [[AbleMind 的一句话定位]]，不在本库另立节点）
当前对护城河的立场：**多模型 = 船票非船；唯一结构性护城河 = 自动累积、时间版本化的专有 conviction 账本；
今日真值 = 0（产出在外流、捕获泵未自动点火）。** 与"有序承诺"一致：押 A、认今日是 B、生死手仍是自动捕获泵。
