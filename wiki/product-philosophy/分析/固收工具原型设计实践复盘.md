# 固收工具原型设计实践复盘

把一次固收工具产品原型设计实践（[[固收资产过程管理工具]]）结晶成可复用的设计要点。

## 迭代弧线
十问定位 → 主视觉 → 单组合驾驶舱 → 舰队对齐 → 调仓工作台 →（红队）→ 关注台 + 穿透下钻 →（图主导）→ 磁力对齐汇总 + 调仓影响。
转折点是 [[2026-06-16-固收工具四方红队评审]]：四个异构模型一致指出"把对的意图（注意力投影）做成了过度承诺（替代全表 + 伪可执行建议 + 伪实时）"。

## 结晶出的设计要点
- 投影范式（控制面 / 注意力投影）：原始全表"读它没用"，主视图 = 投影成少数例外信号——并入 [[乔布斯产品哲学映射智能体工作区3.0]]，是"图谱→4 信号投影"在债券组合上的同构。
- [[渐进式披露]]、[[图主导]]、[[磁力对齐]]、[[影响前后呈现]]、[[不可替代性拷问]]。
- 次级要点（未单独建概念）：三套语义色分离（品牌 / 涨跌红涨绿跌 / 告警 severity）、操作语言从左到右。

## 红队三大要害（四方共识）
1. 数据时效悖论：定时导出（滞后 / 静态）驱动实时监控 + 精确偏离 + what-if，架构级错配。
2. 不可替代性真空 → [[不可替代性拷问]]。
3. 偏离 ≠ 待处理：须区分主动 tilt（alpha 来源）与被动 drift（才该告警）。

## 元教训
对的意图 + 诚实的约束 = 好产品。先承认数据 / 系统约束（[[影响前后呈现]] 的代价侧、关注台的数据时效标注），再谈界面精修。红队（带 sycophancy guard）是把"过度承诺"逼出来的有效手段。
