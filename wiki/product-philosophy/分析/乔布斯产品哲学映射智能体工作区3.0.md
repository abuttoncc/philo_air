# 乔布斯产品哲学映射智能体工作区 3.0

> 派生视图（2026-06-14 讨论结晶）。把乔布斯产品方法论逐条压到用户在建的「智能体工作区 3.0（知识图谱/本体为核心）」设计上。**「3.0 工作区」本身不本体化**（是用户的工具/项目，非哲学知识）——本页是 product-philosophy 概念的应用派生，删了不影响本体。

## 1.0→2.0→3.0 与乔布斯的第一刀
工作区三代真正在变的是重心那个名词：对话(1.0) → 交付物/文件(2.0) → 知识结构/图谱(3.0)。用户卡点是「有了图谱技术、找它有啥用」——正是 [[从用户体验倒推]] 点名的反模式（技术优先、拿着技术找市场）。解药：先定「人每次睁眼要的体验」，再倒推图谱当隐藏引擎。3.0 不可替代的理由：人的知识体系与 Agent 的上下文在此**是同一个对象**（一份资产两个消费者），这才解锁 auto-research。

## 投影的操作形态：照抄 2×2
[[聚焦即说不]] 救苹果是 350→10 + 2×2 矩阵（消费/专业 × 台式/笔记）。3.0 投影照抄：(新鲜/过期) × (掌握/盲区) 四象限，只浮出「过期·盲区」格的告警 + 「盲区」格的派活靶子。「Innovation is saying no to 1,000 things」= 对其余节点说 No。这是上一轮「投影做得够不够狠」的操作化身。

## 带上局限条款（防崇拜）
- [[聚焦即说不]] 局限：说错 No 会错过整个市场（乔布斯对第三方 App 说 No、一年后开 App Store 转弯）→ 狠投影必须留逃生口（周期性看全图），否则减法自造盲区。
- [[端到端控制]] 局限：仅在「能持续做最好产品」时有效（Gates 水平模式曾占 95%）→ 全链自吃的前提是维护得动；08-Ops 自动化层是端到端能成立的**先决条件**。

## 一句话定义（Black Box：图谱消失）
> 它不是知识图谱工具。它是你睁眼就知道「第二大脑昨晚动了什么、哪里需要我」的那块屏——你指一下，它替你去想、去查、去长。

图谱在定义里彻底消失，正是 [[设计即如何运作]] / Black Box 做对的标志：复杂性全藏起来，只露价值。

## 控制面投影范式：从图谱到债券组合（2026-06-17 跨域印证）
本页的「投影做得够不够狠」不是孤例，是一条可命名的范式——**控制面投影**：原始全量（图谱节点 / 债券持仓）"读它没用"，主视图的职责是把它投影成少数几个"要我处理"的例外信号，按例外优先级排，投影是入口非替代（可下钻回全表）。它是 [[聚焦即说不]]（对其余说 No）+ [[从用户体验倒推]]（先定要的体验）在"信息过载"场景的合体。

一次真实产品实践检验了它：[[固收资产过程管理工具]] 把"图谱→4 信号投影"同构搬到"上百债券组合→今天先看这几条"。
- **印证**：投影范式跨域成立——[[图主导]] 是 [[设计即如何运作]] 的延伸；[[渐进式披露]] 是 [[隐形工艺]] 的交互实现；[[磁力对齐]] / [[影响前后呈现]] 是 [[从用户体验倒推]] 的操作化。
- **修正（逃生口的实证）**：四方红队（[[2026-06-16-固收工具四方红队评审]]）指出投影一旦越界成"替代全表 + 伪可执行建议 + 伪实时"就翻车——正是本页"狠投影必须留逃生口"局限条款的真实代价。[[不可替代性拷问]] 即 [[死亡过滤器]] 的立项期形态。
