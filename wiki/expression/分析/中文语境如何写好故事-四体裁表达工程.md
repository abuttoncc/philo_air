# 中文语境如何写好故事——四体裁表达工程

同一个人，写公文四平八稳，写公众号却干巴巴；技术过硬，一到研究报告就把结论埋在第八页。问题几乎从不是"文笔"，而是**用错了配方**：把该讲清楚的写成了散文，把该讲动人的写成了说明书。

这篇想说清一件事：公文、研报、科技博客、公众号，看着是四种写法，其实是**同一根轴上的四个刻度**。搞懂那根轴，四种就都通了。

## 一、一个底层判断：四种体裁，同一根轴

[[表达双轴与叙事结构综述|做好表达]]靠两根正交的轴：

- **[[金字塔原理|金字塔]]**——逻辑的空间结构，管**讲清楚**。结论先行，层层收敛。
- **叙事（[[勾立转收]]）**——注意力的时间结构，管**讲动人**。勾住、蓄势、反转、收尾。
- 两根轴的铰链是 [[SCQA]]：一段"情境→冲突→疑问→回答"，前半是故事，后半是逻辑。

**关键命题：体裁不决定写法，读者状态决定写法。** 四种体裁只是落在这根"金字塔↔叙事"轴上的四个点：

```
纯逻辑 ←————————————————————————→ 纯叙事
公文报告   研究报告   科技博客   微信公众号
（结论先行） （SCQA开场） （对半）   （悬念到底）
```

判准一个读者，看两个坐标：

1. **权力关系**：读者是"必须听你的"（服从），还是"随时可以走"（自愿）。这决定你能不能命令、要不要讨好。
2. **注意力状态**：读者是"赶时间要答案"，还是"愿意被你带着走"。这决定结论该先给还是后给。

公文的读者是上级，服从且赶时间，所以**结论先行、零悬念**；公众号的读者是路人，自愿且随时划走，所以**必须先勾住、结论甚至可以不给**。其余两种在中间。

## 二、中文自己的三样东西（不写成翻译腔的关键）

上面那根轴是通用的。但"用**中文**写好"，还有三样西方框架里没有、必须本土处理的东西。

**1. 凤头·猪肚·豹尾。** 元代乔吉论作文有法："凤头、猪肚、豹尾"——开头要**小而出彩**（凤头），主体要**饱满有料**（猪肚），结尾要**干脆有力**（豹尾）。这是中文版的"勾立转收"，血脉直通话本、"三言二拍"那套让人"拍案惊奇"的说书传统。它比西方框架更强调**开头和结尾这两端**：中文读者对头尾的记忆，远重于中间。

**2. 文气与势。** 中文靠句子的长短、四字格、排比、对仗来控制节奏。[[起承转合]]里的"承"，本质是**蓄势**——用一组同构的句子把气提起来，到"转"处一泄。相声的贯口是这门功夫的极致。写中文不调节奏，句子再对也发闷。

**3. 讲人话，去翻译腔。** 中文写作的头号杀手不是没文采，是**翻译腔**：名词化（"进行了一次深入的探讨"）、长定语（"一个能够有效解决用户痛点的方案"）、滥用"性/化/们/被"、空洞的排比三连。检验只有一招：**念出来**。拗口就是坏句。

还有一条贯穿四体裁的暗线：**每种体裁都有一份"社会契约"**，规定了"我"能出现多少、能煽情多少。公文里几乎不能有"我"；公众号里"我"就是全部。

## 三、四体裁分述

每种按同一张模板拆：读者与契约 → 轴配比 → 骨架 → 凤头怎么起 → 正反例 → 头号死法。

### 3.1 公文报告：纯金字塔，先说结论，零悬念

- **读者与契约**：上级或组织，权力关系是**服从**。他不需要被打动，只需要**看懂、照办**。"我"的浓度趋近于零，形容词、悬念、文学腔都是杂音。
- **轴配比**：几乎 100% 金字塔。悬念是大忌——领导没耐心陪你猜。
- **骨架**：正文三段式 = **缘由 → 事项 → 要求**，也就是中文版的结论先行。请示的内核是"是什么 → 为什么 → 怎么办"。
- **凤头**：开门见山，第一句就交代事由或结论。"现就……请示如下"。
- **豹尾**：一个明确的动作请求。"妥否，请批示""特此报告"。
- **正 / 反**：
  - ✗ "随着经济社会的不断发展，为进一步加强和改进……"（绕三圈还没说事）
  - ✓ "现就我处 2026 年设备更新预算追加事项请示如下：一、……"
- **头号死法**：把结论埋在最后、绕圈子、掺情绪。公文的"转"不存在——想让人照办，就别让人猜。

### 3.2 研究报告：金字塔为主，SCQA 开场，"转"=反直觉发现

- **读者与契约**：专业读者，带着**审视**来。要的是"可信 + 可辩护"。
- **轴配比**：金字塔主导，但开头需要一小段叙事把问题**框起来**——这正是 [[SCQA]] 最合身的地方。
- **骨架**：**摘要（结论先行）→ SCQA 背景 → 方法 → 发现（MECE）→ 结论 → 建议**。SCQA 在这里是：现状（情境）→ 现状里的反常或缺口（冲突）→ 那意味着什么（疑问）→ 我们的结论（回答）。
- **凤头**：执行摘要。一段话给出全部结论，让忙人读完这段就能决策。
- **转**：研报唯一合法的悬念，是**一个反直觉的发现**——数据推翻了常识。但它必须"回头看必然"，证据足够硬，否则就是标题党。
- **正 / 反**：
  - ✗ 先讲三页方法论，结论藏在第八页
  - ✓ "市场普遍认为 A（情境），但最近三个季度的数据持续背离（冲突），这是否意味着拐点（疑问）？我们判断是，理由有三（回答）。"
- **头号死法**：把"过程"当"结论"写；论据不 MECE（既重叠又有漏）；结论后置。

### 3.3 科技博客：对半，勾用叙事、正文用逻辑

- **读者与契约**：同行，为解决**一个具体问题**而来，半主动——你有用他就留，啰嗦他就走。
- **轴配比**：两根轴各一半。开头用故事勾住，正文切金字塔讲清楚。
- **骨架**：**一个真实的坑（勾·叙事）→ TL;DR（结论先行）→ 原理与方案（逻辑）→ 可复现的验证 → 收（局限与下一步）**。SCQA 也好使：我们遇到什么问题 → 为什么现成方案不行 → 怎么解的。
- **凤头**：一个具体的痛点场景，或一个反直觉的结论。**别从"随着……的发展"起手**。
- **转**："其实真正的原因是 Y"——打破读者对这个问题的第一直觉，是技术文章最爽的一拍。
- **正 / 反**：
  - ✗ "随着人工智能技术的飞速发展，大模型在各行各业……"
  - ✓ "上周三凌晨，服务突然雪崩。我们查了六个小时，根因在一个谁都不会怀疑的地方：一行日志。"
- **头号死法**：堆术语不给 TL;DR；不可复现（贴不出能跑的最小例子）；从行业背景讲起而不是从问题讲起。

### 3.4 微信公众号：纯叙事，勾是生死线

- **读者与契约**：刷手机的路人，零义务，**三秒可走**。权力关系是平等、甚至要略微讨好。"我"的浓度最高。
- **轴配比**：几乎 100% 叙事。悬念最重，结论可以最后给，甚至只给情绪不给结论。
- **骨架**：**标题（决定打开率）→ 黄金开头（第一屏定生死）→ 情绪推进 → 反转/共鸣爆点（转）→ 豹尾（金句 + 社交货币）**。
- **凤头**：要狠。直接抛冲突、金句、或一个画面。铺垫是奢侈品，你没有那个时间。
- **猪肚**：靠节奏撑——短句、空行、口语、加粗，让手指停不下来。
- **豹尾**：一句能被**转发**的话。结尾不是总结，是给读者一份"社交货币"：让他愿意把这篇甩到群里，替自己发声。顺带引导在看、留言。
- **正 / 反**：
  - ✗ "今天想和大家聊一聊关于成长这个话题。"
  - ✓ "28 岁那年我裸辞了。三个月后我后悔了——但不是你以为的那种后悔。"
- **头号死法**：开头铺垫太长；端着、不说人话；结尾没有能被转发的那句话。

## 四、一张表看懂配比

| 维度 | 公文报告 | 研究报告 | 科技博客 | 微信公众号 |
|---|---|---|---|---|
| 读者/权力 | 上级·服从 | 同行·审视 | 同行·互助 | 路人·自愿 |
| 注意力 | 赶时间 | 要严谨 | 找答案 | 随时划走 |
| 主轴 | 金字塔 | 金字塔+SCQA | 对半 | 叙事 |
| 悬念浓度 | 无 | 一处（反直觉发现） | 中 | 满 |
| "我"的浓度 | 无 | 低 | 中 | 高 |
| 结论位置 | 最前 | 最前（摘要） | 靠前（TL;DR） | 最后/不给 |
| 凤头 | 开门见山说事由 | 执行摘要 | 一个真实的坑 | 冲突/金句 |
| 豹尾 | 明确请求 | 可执行建议 | 可复现+下一步 | 可转发的金句 |
| 头号死法 | 埋结论、绕圈 | 过程当结论 | 堆术语、不可复现 | 开头太慢、端着 |

## 五、一套可迁移的自检（[[勾立转收]] × 中文）

不管写哪种，收尾前过一遍：

- **勾**：第一屏（或第一句），读者凭什么不走？越往叙事端，这一关越致命。
- **立（猪肚）**：主体够不够充实、有没有给读者一个能预测的模式？空洞就是没"料"。
- **转**：有没有一个"回头看必然"的意外或洞见？公文无转；研报的转是反直觉发现；博客是"真因"；公众号是情绪反转。**没铺垫的意外是狗血，没意外的铺垫是说教。**
- **收（豹尾）**：结尾给读者留下了什么可带走的东西？公文=明确要求，研报=可执行建议，博客=可复现+下一步，公众号=社交货币。
- **中文关**：念出来顺不顺？有没有翻译腔（名词化、长定语、"进行/性/化"）？长短句和四字格有没有调过节奏？

## 结语

写好一个中文故事，不是背模板，是**按人下菜**：先判准读者站在"服从↔自愿""赶时间↔愿沉浸"的哪个位置，再在金字塔和叙事之间调配比，最后用中文自己的气把它走顺。

说到底，四种体裁不过是在处理同一对矛盾——**结论先行**和**悬念留白**。公文把天平压死在前者，公众号压死在后者，研报和博客在中间找平衡。凤头抓人、猪肚充实、豹尾有力，是这对矛盾在中文里的老规矩。剩下的，交给你对读者的判断。
