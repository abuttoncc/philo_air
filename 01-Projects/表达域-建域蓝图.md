## A. 第二根轴已补齐：金字塔原理（明托，已核实）

芭芭拉·明托《金字塔原理》：中心论点 → 3~7 论据支撑，层层展开状如金字塔。

- **四原则**：**结论先行**（每篇只有一个中心思想，放最前）· **以上统下**（每层是对下层的总结概括）· **归类分组**（每组同一逻辑范畴，即 MECE）· **逻辑递进**。
- **纵向关系** = **疑问/回答式对话**（Q&A）：每个论点都在回答上一层引出的疑问。
- **横向关系** = **演绎 or 归纳**（同组内二选一，不混用）。演绎＝线性三段论（大前提+小前提→"因此"）；归纳＝归类共同性得结论。关键句层次用归纳比演绎更好读。
- **序言 = SCQA**：背景(S情境) → 冲突(C) → 疑问(Q) → 回答(A)。冲突因背景而生；背景与冲突都是读者**已知事实**；冲突逼出疑问，疑问引出作者答案。
- **逻辑顺序三种**：时间/步骤、空间/结构、程度。
- **MECE**：相互独立、完全穷尽（不重叠、无遗漏）。

> **命门印证**：明托把序言明确叫作**"讲故事形式"**，且核心是**"冲突"**——金字塔的前门本来就是一个微型故事。这直接坐实了双轴接口就在 SCQA。

---

## B. 表达双轴模型（总结）

**表达 = 空间轴（金字塔）× 时间轴（叙事），SCQA 是铰链。**

| | 金字塔（明托） | 叙事（勾立转收） |
|---|---|---|
| 管 | 逻辑的**空间结构**（WHAT·树） | 注意力的**时间结构**（ORDER·流） |
| 形态 | 静态：结论先行·以上统下·MECE·逻辑递进 | 动态：勾→立→转→收 |
| 为了 | 说服（严谨、完整、可信） | 吸引（情绪、悬念、记忆） |

**主要矛盾：结论先行 vs 悬念留白。** 金字塔要你现在就说答案，叙事要你先别说——方向相反。判为**非对抗性矛盾**，化解靠**先判听众状态**再定主轴：

- 听众已对齐 / 赶时间 / 要决策 → **金字塔主导**，结论先行。
- 听众存疑 / 需被打动 / 要认同 → **叙事主导**，先建张力。
- **SCQA 是接力点**：叙事的"勾-立"（情境-冲突）买注意力、逼出问题；金字塔的"结论先行"高效兑现。**叙事前置吸引，金字塔后置严谨。**

> 一句话第一性：**时间轴走对（勾立转收）× 空间轴搭对（结论→MECE分组→论据），先按听众状态决定哪根轴主导。**

有意思的不对称：金字塔的 **`结论先行`** 在叙事里**没有对应物**——它恰是"悬念"的反面。这条"缺失的对应边"本身就是双轴张力的证据，值得在图谱上标出来。

# Philo Vault · 表达领域本体契约

> `wiki/expression/` 的本体定义。ingest/recall 前先读本页。与 [[wiki/metaphysics/_ontology|metaphysics 母本]]
> **共用同一套 6 档时间模型、退役不删除协议与三分铁律**——本页只声明 表达 领域特有的节点类型与受控关系词表。

## 0. 总原则（同母本）
1. 节点 / 数据 / 边 三分：结构框架是节点、关系是边、分类标签是边。
2. 编译单向：Inbox(散文) → ingest → wiki(本体)。
3. 退役不删除：T1/T2/T3 任何变化＝旧行封 valid_to + 插新行，必有 T4 事件盖章。

## 1. 节点判据
能指向「就是这一个」、明年同名还指同一个 → 实体；必须先讲机理才懂 → 概念。
**本域关键提示**：有专名、可整体指认的**结构框架**（金字塔原理 / 救猫咪十五拍 / 起承转合 / 相声四段式）
归 `框架/`（既不是"概念"也不是"分析"）；框架的**组成部件**（勾/立/转/收、SCQA 四要素、垫话/瓢把儿/正活/底）
是概念，用 `part_of` 挂回所属框架。

## 2. 节点类型（=目录=图谱着色）
| 类型 | 子目录 | 判据 | 例子 |
|---|---|---|---|
| 实体·人物 | `人物/` | 有专名的表达理论源头 | 芭芭拉·明托、布莱克·斯奈德、杨载、亚里士多德、罗伯特·麦基 |
| 实体·著作 | `著作/` | 有专名文本，书名号《》开头 | 《金字塔原理》《Save the Cat!》《诗法家数》《故事》《修辞学》 |
| 框架 | `框架/` | **有专名、可整体指认的结构模型/模板（本域签名类型）** | 金字塔原理、救猫咪十五拍、起承转合、相声四段式、勾立转收、SCQA、三幕结构 |
| 概念 | `概念/` | 必须先讲机理才懂的抽象/局部技法 | 结论先行、以上统下、归类分组(MECE)、逻辑递进、悬念、预期管理、包袱、三翻四抖、移情、首尾呼应 |
| 案例 | `案例/` | 被拆解的具体表达样本（可指认主体+时段，功能是例证） | 乔布斯斯坦福演讲叙事拆解、某 pitch 结构复盘 |
| 分析 | `分析/` | 研究课题派生视图（删了不影响本体） | 叙事结构跨传统综述、表达双轴模型综述 |
| 来源 | `来源/` | 讲义/文字稿/摘录（注明 source_type） | 叙事结构研究笔记、金字塔原理摘录 |

> 易踩的坑：「三翻四抖」像框架但它是**局部技法** → `概念/`，用 part_of 挂到「相声四段式」；
> 「勾立转收」是本库综合出的**元框架** → `框架/`；「结论先行」是金字塔的部件概念 → `概念/` + part_of。

## 3. 受控关系词表（expression 特有；通用词沿用母本）

本域特有增量：
- `对应`（框架元素/概念 ↔ 另一框架的元素/概念，跨框架等价对应）：**本域签名边**（位置相当于母本的 grounds）。
  例：勾 →对应→ 起；起 →对应→ 垫话；转 →对应→ 抖包袱；SCQA的冲突 →对应→ 叙事的转。整份跨传统综述就编码在这类边里。
  双向语义，lint 允许任一方向登记一次即可。
- `exemplifies`（案例 → 框架/概念，借自 product-philosophy）：被拆解的表达样本例证某框架/技法。
  例：乔布斯斯坦福演讲 →exemplifies→ 勾立转收。

沿用母本：`proposed_by`(框架/概念→人物) · `authored_by`(著作→人物) · `appears_in`(框架/概念→著作) ·
`part_of`(概念→框架，用于"框架的组成部件") · `instance_of`(具体框架→抽象框架，如 救猫咪十五拍→三幕结构) ·
`supports`/`critiques` · `develops`(后继→前驱) · `classified_as`(→分类标签) · `references`(分析/来源→任意)。
