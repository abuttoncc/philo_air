# 写好中文文章 (cn-article)

## 一句话心法

**体裁不决定写法,读者状态决定写法。** 公文、研报、科技博客、公众号是同一根"金字塔↔叙事"轴上的四个刻度——由读者的**权力关系**(服从↔自愿)和**注意力状态**(赶时间↔愿沉浸)决定配比。

```
纯逻辑 ←────────────────────────→ 纯叙事
公文报告   研究报告   科技博客   微信公众号
```

## 四件事,先分是哪件

- **写全程**(帮我写一篇)→ 谋篇 → 成文 → 润色,走完三段。
- **只润色**(改改这段 / 去翻译腔 / 去AI味 / 太机器 / 没人味)→ 直接跳「润色三道」。
- **判怎么写**(这篇该怎么写 / 搭骨架)→ 只做「谋篇」前两步。
- **吃案例**(吸收这篇 / 拆进案例库)→ 读 `references/案例吸收协议.md`。

## 谋篇（planning）

1. **判读者** — 定位两坐标:权力关系(服从↔自愿)、注意力(赶时间↔愿沉浸)。**不确定就问一句**(写给谁看、在哪发),别猜。
2. **定配比** — 据读者定"金字塔:叙事"比例、悬念浓度、"我"的浓度、结论位置。选体裁 → `references/谋篇/四体裁配方.md`。
3. **搭骨架** — 先列 outline。勾立转收或体裁骨架(公文三段式/研报SCQA/博客问题-方案)→ `references/谋篇/双轴与勾立转收.md`;中文的头尾与气 → `references/谋篇/凤头猪肚豹尾与文气.md`。

## 成文（write）

凤头(勾)要狠、猪肚(立)要实、豹尾(收)要留东西;转要"回头看必然"。**动笔时就按去翻译腔的句法写对**(见润色第一道),别写完再救。

## 润色（polish · 三道,由粗到细）

写完自己的稿、或收到别人的稿,依次过三道:

1. **去翻译腔**(句法根子,先过)→ `references/润色/去翻译腔.md`。被动改主动、拆破折号、少用"是…的"、一句一意。
2. **去AI味**(修辞痕迹)→ **按稿子类型选载,别全量堆进上下文**:
   - 通用三篇:`去AI味-内容模式.md`(夸大意义/空洞分析/模糊引用) + `去AI味-语言模式.md`(AI高频词/排比三连/否定平行) + `去AI味-风格与冗词.md`(破折号/粗体/emoji/客服套话/赘语)
   - 正式文体(研报/公文/学术)**另加** `去AI味-正式文稿.md`(框架词/大词/术语堆砌/空泛结论/八股)
3. **注入灵魂**(别做无菌文字)→ `references/润色/注入灵魂.md`。去干净还不够:敢有观点、长短句交错、该用"我"就用、接纳复杂、具体表达感受。**配合体裁**——公文不要"我",公众号靠情绪活。

## 吃案例（技能长大的唯一方式）

用户投喂真实范文时**不要只夸好,要拆解入库**:按 `references/案例吸收协议.md` 生成拆解卡 → 存 `cases/` → 更新 `cases/_index.md` 复现模式。跨案例(≥3 卡)共性才升"模式"。只存不炼等于没长大。

## 发出前自检

- 谋篇:勾/立/转/收都在?转"回头看必然"吗?配比对不对读者?
- 句法:念出来顺吗?有"被X"/破折号塞半句/排比三连/名词化?
- AI味:有夸大意义/万能过渡词/模糊引用/空洞积极结尾?
- 灵魂:像一个人在讲话吗?有观点和温度吗?(公文除外)
