## 配比总表

| 维度 | 公文报告 | 研究报告 | 科技博客 | 微信公众号 |
|---|---|---|---|---|
| 读者/权力 | 上级·服从 | 同行·审视 | 同行·互助 | 路人·自愿 |
| 注意力 | 赶时间 | 要严谨 | 找答案 | 随时划走 |
| 主轴 | 金字塔 | 金字塔+SCQA | 对半 | 叙事 |
| 悬念浓度 | 无 | 一处(反直觉发现) | 中 | 满 |
| "我"的浓度 | 无 | 低 | 中 | 高 |
| 结论位置 | 最前 | 最前(摘要) | 靠前(TL;DR) | 最后/不给 |
| 凤头 | 开门见山说事由 | 执行摘要 | 一个真实的坑 | 冲突/金句 |
| 豹尾 | 明确请求 | 可执行建议 | 可复现+下一步 | 可转发的金句 |
| 头号死法 | 埋结论、绕圈 | 过程当结论 | 堆术语、不可复现 | 开头太慢、端着 |

## 公文报告

- **读者与契约**：上级或组织，权力关系是**服从**。不需要被打动，只需**看懂、照办**。"我"、形容词、悬念、文学腔都是杂音。
- **骨架**：正文三段式 = **缘由 → 事项 → 要求**（中文版结论先行）。请示内核＝是什么 → 为什么 → 怎么办。
- **凤头**：开门见山，第一句交代事由或结论。"现就……请示如下"。**豹尾**：明确动作请求。"妥否，请批示""特此报告"。
- **正/反**：✗"随着经济社会不断发展，为进一步加强……"（绕圈）｜ ✓"现就我处 2026 年设备预算追加事项请示如下：一、……"
- **红线**：埋结论、绕圈子、掺情绪。公文没有"转"——想让人照办，别让人猜。

## 研究报告

- **读者与契约**：专业读者，带**审视**来。要"可信 + 可辩护"。
- **骨架**：**摘要(结论先行) → SCQA 背景 → 方法 → 发现(MECE) → 结论 → 建议**。SCQA＝现状(情境) → 现状里的反常/缺口(冲突) → 意味着什么(疑问) → 结论(回答)。
- **凤头**：执行摘要，一段话给出全部结论，忙人读完即可决策。**豹尾**：可执行的建议。
- **转**：唯一合法悬念＝一个**反直觉发现**（数据推翻常识），但必须"回头看必然"，证据够硬。
- **正/反**：✗ 先讲三页方法论、结论藏第八页 ｜ ✓"市场普遍认为 A，但近三季数据持续背离，这是否意味着拐点？我们判断是，理由有三。"
- **红线**：过程当结论；论据不 MECE（既重叠又有漏）；结论后置。

## 科技博客

- **读者与契约**：同行，为解决**一个具体问题**而来，半主动——有用就留，啰嗦就走。
- **骨架**：**一个真实的坑(勾·叙事) → TL;DR(结论先行) → 原理与方案(逻辑) → 可复现验证 → 收(局限/下一步)**。SCQA 也好使：遇到什么问题 → 为什么现成方案不行 → 怎么解。
- **凤头**：一个具体痛点场景或反直觉结论。**别从"随着……的发展"起手。转**："其实真正的原因是 Y"，打破读者第一直觉。
- **正/反**：✗"随着人工智能技术飞速发展，大模型……" ｜ ✓"上周三凌晨服务雪崩。查了六小时，根因在一个谁都不会怀疑的地方：一行日志。"
- **红线**：堆术语不给 TL;DR；不可复现；从行业背景讲起而非从问题讲起。

## 微信公众号

- **读者与契约**：刷手机的路人，零义务，**三秒可走**。权力关系平等甚至要略讨好。"我"的浓度最高。
- **骨架**：**标题(决定打开) → 黄金开头(第一屏定生死) → 情绪推进 → 反转/共鸣爆点(转) → 豹尾(金句 + 社交货币)**。
- **凤头**要狠：直接抛冲突、金句、画面，没时间铺垫。**猪肚**靠节奏——短句、空行、口语、加粗。**豹尾**＝一句能被转发的话（给读者社交货币，替他发声），顺带引导在看/留言。
- **正/反**：✗"今天想和大家聊聊关于成长这个话题" ｜ ✓"28 岁那年我裸辞了。三个月后我后悔了——但不是你以为的那种。"
- **红线**：开头铺垫太长；端着、不说人话；结尾没有能被转发的那句话。

## 不在四类里怎么办

新体裁（演讲 / 推文 / PPT / 邮件 / 小红书……）：先判读者两坐标定位到轴上，就近借最像的配方微调：

- **演讲** ≈ 公众号 + 现场反馈：更重节奏、停顿、重复；金句要能被听觉记住。
- **推文/短帖** = 极限公众号：勾即一切，第一句不炸就没有然后。
- **内部邮件** ≈ 轻量公文：结论先行，但可以有"我"、可略带温度。
- **PPT** = 金字塔可视化：每页一个论点（以上统下），一页只讲一件事。
- **小红书** = 公众号 + 更强的"我"和场景感：第一张图/首行是凤头。
