# 去 AI 味 · 风格与冗词（13–23）

> 吸收自 humanizer-zh。表层格式痕迹 + 对话冗词。这类最好扫，一眼可见。

## 风格格式（13–17）

- **13 破折号滥用**：AI 用破折号制造"俏皮/强调"，过度。
  - ✗ 主要由荷兰官方推广——而非当地人自称——但在正式文件中——甚至学术论文里——仍频繁出现。
  - ✓ 主要由荷兰官方推广，当地人并不这么自称，但正式文件和学术论文里仍频繁出现。
- **14 粗体滥用**：动不动加粗，用格式套路强调。→ 去掉非必要加粗。
- **15 标题式列表**（`**标题：** 内容`）：像写报告大纲。
  - ✗ - **用户体验：** 新界面显著提升体验。 - **性能优化：** 大幅提高性能。
  - ✓ 新版优化了界面，加载更快，并增加了端到端加密。（列点 → 成句）
- **16 标点格式**：滥用书名号/引号、中英标点混用 → 统一中文常规标点。
- **17 Emoji 滥用**：标题/列表前加 🚀💡✅ 显花哨 → 去掉。

## 交流冗词（18–23）

- **18 客服套话**：希望以上内容对您有帮助、如有问题随时告诉我、我将尽力解答 → 删。
- **19 知识截止声明**：截至某日、据现有资料、由于资料有限 → 删；有确据就给确据（"据注册文件，成立于 1994 年"）。
- **20 讨好口吻**：这个问题问得好、您非常敏锐、您说得完全正确 → 删，直接接话。
- **21 赘语**：
  - "为了达到这个目标"→"为此" ｜ "在这个时间节点上"→"现在" ｜ "系统具备处理大量数据的能力"→"系统能处理大量数据" ｜ "值得注意的是，数据显示"→"数据显示"
- **22 过度模糊**：每句都"或许可能一定程度上" → 有判断就直说。
  - ✗ 这项政策或许可能对某些方面产生一定的积极影响。 ✓ 这项政策可能有助于改善就业。
- **23 空洞的积极结尾**：前景光明、未来可期、继续追求卓越 → 换成具体动作。
  - ✗ 公司未来充满希望，激动人心的时刻即将到来。 ✓ 公司计划明年再开两家分店。
