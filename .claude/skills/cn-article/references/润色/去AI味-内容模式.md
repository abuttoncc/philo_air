# 去 AI 味 · 内容模式（1–6）

> 吸收自 humanizer-zh。内容层的 AI 痕迹：给普通事物强加宏大意义、堆砌而不给实质。逐条对照 警惕词 + 反例→正例。

## 1. 过度强调意义、传承、宏大趋势
**警惕词：** 标志着、见证了、发挥了重要作用、扮演着不可或缺的角色、折射出、深刻反映了、具有深远意义、为……奠定了基础、开创了……新局面、应运而生、方兴未艾
- ✗ 加泰罗尼亚统计局成立，标志着西班牙地区统计事业的里程碑，是全国推进行政分权大潮中的重要一环。
- ✓ 加泰罗尼亚统计局成立于 1989 年，旨在独立于国家统计局，收集发布本地区统计数据。

## 2. 过度强调知名度与媒体报道
**警惕词：** 受到广泛关注、引发热议、被多家媒体争相报道、拥有大量粉丝、活跃于各大平台
- ✗ 她的观点被《纽约时报》《金融时报》引用，社交平台拥有超 50 万粉丝。
- ✓ 2024 年接受《纽约时报》采访时，她提出 AI 监管应更关注结果而非技术本身。（罗列名号 → 给实质内容）

## 3. 空洞的"进行时"分析
**警惕词：** 进一步、从而、进而、以此、得以、致力于、旨在、着重
- ✗ 采用蓝绿金色系与自然风光相呼应，以此象征州花，从而体现社区与土地的深厚联结。
- ✓ 寺庙用了蓝、绿、金三色。设计师说是为了呼应本地的蓝帽花和墨西哥湾。

## 4. 广告式宣传用语
**警惕词：** 坐拥、坐落于、依偎在、风光旖旎、钟灵毓秀、得天独厚、无与伦比、叹为观止、必游之地、不容错过
- ✗ 小镇坐落于风光旖旎之地，充满活力，拥有丰富文化遗产和令人惊叹的自然美景。
- ✓ 这是贡德尔地区的一个小镇，以每周集市和一座 18 世纪教堂闻名。

## 5. 模糊引用与"据说"
**警惕词：** 业内人士指出、观察家认为、有专家表示、有观点认为、据相关报道（无来源）
- ✗ 专家认为它在区域生态系统中起着关键作用。
- ✓ 根据中国科学院 2019 年调查，濠来河是几种特有鱼类的栖息地。（观点落到具体出处）

## 6. 套路化的"挑战与前景"段落
**警惕词：** 尽管仍面临诸多挑战、面对困境、展望未来、未来可期、机遇与挑战并存
- ✗ 尽管面临交通拥堵等城市问题，凭借战略位置，该市正持续发展。
- ✓ 2015 年三家 IT 园区落成后交通拥堵加剧，2022 年市政启动了雨洪排水工程。（模板 → 具体事实）
