# 去翻译腔（句法层 · 动笔时就写对）

> 吸收自 cn-writer。中文写得不自然，多半不是用词不对，是三个根子在作怪。先认根子，再用规则。这是润色三道里的**第一道**，也是成文时就该守的。

## 三个根子

1. **用英文的句子骨架写中文。** 被动句、破折号插入语、"是……的"判断句、把动作写成名词、一层套一层的修饰——这些是英文结构习惯。中文偏爱主动、短句、话题在前、动词带动。骨头是英文的，换成汉字也涩。
2. **用密度和节奏冒充逻辑。** 排比、加粗、堆术语、造新词，能做出"很有条理"的样子，但节奏只*暗示*了关系，没把关系讲出来。读者觉得字都认识、连起来不通——这就是"逻辑错乱"的来源。三根子里这个最该先改。
3. **不给读者留缓冲。** 自造词不解释、英文术语直接塞、比喻打完不落地、表格和正文不搭话。读者脑子被塞满，喘不过气。

## 改写规则（反例 → 正例）

1. **被动改主动。** 能说谁做了什么，就别用"被"。
   - ✗ 系统提示词，是被指示的设计原则。 ✓ 系统提示词，是我们给模型定下的设计原则。
2. **拆掉破折号链。** 把插在句中的解释，挪成前后独立短句。
   - ✗ ——同一种层级优先思维——提示词分层写。 ✓ 这是同一种"先归层"的思路：提示词按优先级分层。
3. **少用"是……的"下定义。** 换成动词句。
   - ✗ 这是模型在性情底座上自带的增量。 ✓ 这层东西不是提示词教的，是模型面对代码时自己长出来的。
4. **新词先稀释。** 自造简称第一次出现，先用白话解释，之后再用简称。
5. **英文术语加缓冲。** 第一次给中文意译，混排时用引号或代码格式裹一下。
   - ✗ L4 检索 epistemics。 ✓ L4 的检索认识论（epistemics）。
6. **比喻要落地。** 打完比方，补一句翻回具体领域。
7. **表格/标题前后搭句话。** 别让表格凭空出现、戛然而止。
8. **语气别打架。** 一篇里别一会儿"最值钱"、一会儿"回溯到基因型"，通篇专业而亲切。

## 一句话原则

一句话只说一件事。主语写清楚。短句优先。能不用的术语就不用，非用不可先解释。不靠排比和加粗显得有条理，靠把道理一步步讲通。

## 自检

- [ ] "被 X" 能改成主动？
- [ ] 破折号里塞了半句话？拆开。
- [ ] 连用三四个并列短语充节奏？删到只剩真需要的。
- [ ] 自造词或英文词没解释就上场？补一句。
- [ ] 比喻落地了？表格前后搭话了？
- [ ] 通读一遍：像不像一个人在跟我讲话？
