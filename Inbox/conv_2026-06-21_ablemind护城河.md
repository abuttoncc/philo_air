# 拾遗候选 · AbleMind 的护城河盘点(2026-06-21)

## 候选 1 — 护城河 ≠ 先发优势;用复制成本反演判 AbleMind
- **claim**:AbleMind 最显眼的东西(深度金融 MCP 工具链 / casting / 模型路由 / latency /
  三层沙箱 / 语音)**全是先发优势,不是护城河**。用 [[竞争优势模式]] 的**复制成本反演分析**判:
  它们是「白酒,易仿」——通用模型在逼近「更快更懂金融的 chat」,集成是花钱可追平的时间差。
  这正是定位里那个**已被判可替代的 B**。**含义**:backend 111 : frontend 63 那 ~57% 劳动
  在加固一条**没有护城河的线**。
- **why-long-term**:通用判据(分清护城河/先发优势),且直接指导 AbleMind 的资源分配。
- **时间档**:T2 原则。
- **连接提示**:`develops` [[竞争优势模式]](复制成本/反演);`references` [[AbleMind 的一句话定位]] 的 A/B。

## 候选 2 — 唯一结构性护城河 = 累积型 conviction 资产(复制成本 + 转换成本同一面)
- **claim**:套 12 模式,AbleMind 真能落护城河的只有两格、且是一件事的两面:
  ① **复制成本(陈年烈酒)**——一本 append-only、时间版本化的论点账本(每标的「现在信什么·
  为什么·何时变·什么击穿·哪条馊」的**演化史**),价值随使用时间**复利**,买不到/抄不来/速不成;
  ② **转换成本(剃刀-刀片)**——账本越厚离开越痛,「人走不带走」。这就是定位里的 **A**,
  AbleMind 唯一不可替代的资产,兑现「人的知识体系 = Agent 上下文是同一个对象」。
- **why-long-term**:这是 AbleMind 护城河的根定义,跨会话反复要用。
- **时间档**:T2 原则。
- **连接提示**:`grounds` 「活体论点账本」3.0 vision;`develops` [[竞争优势模式]](复制成本/转换成本)。

## 候选 3 — 今天护城河真值 = 0,因为没在累积;前提是「捕获免费」
- **claim**:护城河是**累积出来的状态**,而现在没在累积——捕获泵已退役无自动点火→**账本无源**,
  没有真实分析师在喂→没有 conviction 沉淀。手动 seed 能演 demo,**演不出护城河**
  (护城河本质 = 时间 + 自动累积)。把 [[不可替代性拷问]] 红队结论直接套上即判决:
  「若不可替代性只是视觉整合,**维护成本会超过收益**」——需要人手维护的账本不是护城河,
  维护成本会吃掉护城河本身。**故护城河的前提不是某功能,是「捕获必须免费(自动)」**;
  泵死则 A 退化成 PPT。
- **why-long-term**:把「捕获泵=生死手」从定位侧迁到护城河侧,论证更硬(护城河需自动累积才成立)。
- **时间档**:T2 原则。
- **连接提示**:`grounds` 捕获泵设计;`develops` [[不可替代性拷问]](维护成本>收益);
  与 [[conv_2026-06-20_ablemind飞轮]] 候选 4「捕获免费、晋升收紧」互证。

## 候选 4 — 护城河升级阶梯:个人转换成本 → 组织资本 → 真网络效应
- **claim**:这条护城河有三档,只能逐级升:① **个人转换成本**(今天的 A,最弱单点档);
  ② **组织资本**(定位候选 C 团队共享大脑,「人走知识不走」+ 金融信任/合规可成监管资本);
  ③ **真网络效应**(机构间 conviction 互通 / 委派彼此差异化专家 agent,inbox A2A substrate)。
  ②→③ 是从「转换成本护城河」跳到「网络效应护城河」的**唯一通道**。**时间对这类护城河是盟友
  (复利),但只在飞轮转起来之后;在那之前时间是在浪费。**
- **why-long-term**:给护城河一条可执行的演化路线,指导从弱档往强档走。
- **时间档**:T2 原则。
- **连接提示**:`references` 定位候选 C / 跨用户 inbox substrate 设计;`develops` [[竞争优势模式]](网络效应缺位)。

## 候选 5 — 个人立场(T1):AbleMind 当前护城河现状判断
- **claim**:当前立场——**AbleMind 今天没有护城河,只有可被复制的先发优势;唯一结构性护城河
  候选(自动累积、时间版本化的个人 conviction)真值为 0,因为没在累积;其唯一前提是捕获免费,
  而那恰是没在建的那半。** 与定位「有序承诺」一致:护城河押在 A,但 A 的护城河今天不存在,
  生死手仍是自动捕获泵。
- **why-long-term**:个人立场时间序列的一个点;会随泵是否建成、是否有真用户喂而演化。
- **时间档**:**T1 立场** —— 应交叉引用回 [[AbleMind 的一句话定位]],不重复 ingest。
- **连接提示**:`references` [[AbleMind 的一句话定位]] 第2答(护城河=A 已盖章,本篇补「真值=0」论证)。
